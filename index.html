📋 出行待办清单

  • 同行人身份证、驾驶证随身携带；车辆行驶证、交强险单据放车上
  • 携带3张星湖湿地VIP科普研学畅游卡，出行前确认卡片激活，仅限本人入园
  • 提前保存两间酒店前台联系电话，保存到手机离线备忘录
  • 出发前全车检查：胎压、机油、雨刮、备胎、玻璃水
  • 备好薄外套、徒步鞋、便携雨伞，山区天气多变
  • 防晒用品、驱蚊液、肠胃药、晕车药、创可贴、个人常备药品
  • 充电宝、车载充电器；车上储备堵车零食与饮用水
  • 七星岩、鼎湖山门票，出行前1-2天公众号预约；星湖湿地凭VIP卡入园，不用线上购票
  • 热门餐厅国庆建议错峰就餐，部分门店无法提前订位，预留排队时间
  • 准备环保袋子，采购裹蒸粽等肇庆特产
  • 确认ETC余额充足，减少高速出入口排队
  • 仙女湖游船建议提前排队；丹顶鹤放飞遇大雨大风会取消，预留备选游玩方案

💡 出行实用贴士

🚙交通贴士

  • 10.1出发、10.6返程属于高速最高峰，建议早于7点出发，避开拥堵时段
  • 肇庆景区道路节假日拥堵严重，尽量早出发；停车场饱和可停外围车位打车入园
  • 导航优先高德，山区部分区域信号弱，提前下载肇庆离线地图包

🍜餐饮贴士

  • 竹篙粉是肇庆特色早餐，敏捷广场门店离第二间酒店步行可达
  • 西江河鲜建议11:30前或13:30之后就餐，避开午市排队高峰
  • 裹蒸粽伴手礼，本地市场购买性价比高于景区商店

🏞️景区贴士

  • 星湖湿地VIP卡：仅仙女湖片区，不含七星岩大门票；激活起有效期一年，无限次入园，不可转让
  • 丹顶鹤放飞：每日10:00、15:00两场，恶劣天气取消，现场可咨询工作人员
  • 湿地湖面风大，游船保管好手机相机；观鸟保持安静，不要惊扰鸟类
  • 鼎湖山山林温度低3~5℃，带薄外套；台阶多，穿防滑徒步鞋
  • 七星岩湖面开阔，游船风大，随身物品做好防水
  • 国庆游客量大，保管随身物品；湖边游玩看好同行人员

📝部署操作步骤（标注电脑必做）

全部代码上传、仓库配置、Cloudflare Workers绑定，均必须电脑浏览器操作；手机只能打开预览网页，无法上传代码

  1. 电脑端登录github.com，新建Public公开仓库，仓库名称自定义，不要勾选README
  2. 电脑本地，复制全部代码，记事本保存为 index.html，编码选择UTF-8
  3. 仓库页面点击Add file → Upload files，上传index.html，填写提交信息Commit changes
  4. 仓库Settings → Pages，分支选择main，根目录/，保存，等待1~3分钟，获得GitHub Pages访问链接，网页可直接打开
  5. 【可选：Cloudflare Workers自动发布】电脑登录Cloudflare，进入Workers & Pages，连接GitHub仓库，授权绑定；后续本地修改html，push提交到GitHub，Cloudflare会自动重新部署上线。
